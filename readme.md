# GymStreak – Gym Management System

GymStreak is a web-based Gym Management System designed to simplify gym operations and improve membership management.

## Features

### Admin
- Dashboard
- Member Management
- Trainer Management
- Membership Management
- Attendance Tracking
- Payment Management

### User
- User Registration and Login
- Personal Dashboard
- Membership Details
- Attendance History
- Payment History
- Profile Management

## Technologies Used

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Payment Integration:** Razorpay Test Mode

## Project Structure

```text
GymStreak/
├── backend/

```

## Installation

1. Clone the repository.
2. Install backend dependencies.
3. Install frontend dependencies.
4. Configure your local environment variables.
5. Start the backend and frontend servers.
